## Govern

### `fabric.MemoryFabric` (stable)

Single-process memory fabric with a governed write and share path.

- **`MemoryFabric.validate(memory_id: str, actor: str, reason: str = 'validated') -> Memory`**
  Promote a candidate to active.
- **`MemoryFabric.quarantine(memory_id: str, reason: str, actor: str = 'operator', propagate: bool = True, basis: str | WithdrawalBasis | None = None) -> list[str]`**
  Quarantine a memory and contest everything derived from it.
- **`MemoryFabric.release(memory_id: str, actor: str, reason: str = 'reviewed and released') -> Memory`**
  Bring a quarantined memory back to candidate after human review.
- **`MemoryFabric.forget(memory_id: str, reason: str, actor: str = 'operator') -> Memory`**
  Deprecate. Deletion is the retention policy's decision, not the caller's, so that a single call can never destroy an audit trail.
- **`MemoryFabric.share(memory_id: str, scope: str | Scope, actor: str = 'operator', granted_capabilities: Iterable[str] = ()) -> FirewallRuling`**
  Promote a memory's scope, if the firewall allows it.
- **`MemoryFabric.challenge(memory_ids: Sequence[str], evidence: str, detector_id: str = 'manual', confidence: float = 1.0, hypothesis_set: str | None = None, actor: str = 'operator') -> str`**
  Open or extend a hypothesis set over contradictory memories.
- **`MemoryFabric.erase_content(memory_id: str, reason: str, actor: str = 'operator') -> bool`**
  Destroy a memory's content key: crypto-erasure.
- **`MemoryFabric.authority(memory_id: str) -> Any`**
  Origin-bound authority of a memory (`authority.py`).
- **`MemoryFabric.elevate(memory_id: str, approver: str, reason: str, policy: str = 'manual-review', revoke: bool = False) -> Any`**
  Lift a memory version's *soft* authority reasons, after review.
- **`MemoryFabric.sweep_retention(apply: bool = False, actor: str = 'retention', actions: Iterable[str] | None = None) -> list[RetentionDecision]`**
  The retention policy's decisions; with `apply`, carry them out.
- **`MemoryFabric.certify(claim_id: str, evidence: Sequence[Any], agent_id: str, tenant_id: str | None = None, required_checks: Sequence[str] = (), min_independent_sources: int = 1, ttl_ms: int | None = 300000) -> EvidenceCertificate`**
  Record the evidence a decision rests on, for re-checking at action time (`certificates.py`). Issuing checks nothing; `verify_certificate` does, against the store as it is then.
- **`MemoryFabric.verify_certificate(certificate: Any, agent_id: str, tenant_id: str | None = None, risk: RiskLevel = RiskLevel.HIGH, mode: str = 'selective') -> CertificateVerification`**
  Re-check every piece of evidence in a certificate, now. Fails closed.

### `sdk.AgentClient` (stable)

What an adapter is given. Deliberately narrow.

- **`AgentClient.recall(query: str, k: int = 5, context: Mapping[str, Any] | None = None, include_contested: bool = False, episode_id: str | None = None) -> list[UsableMemory]`**
  Retrieve, enforced, with a token per result.
- **`AgentClient.fetch(memory_id: str, risk: RiskLevel = RiskLevel.LOW) -> UsableMemory`**
  One memory, by id, enforced. Raises rather than returning None.
- **`AgentClient.verify(usable: UsableMemory, risk: RiskLevel = RiskLevel.HIGH) -> AccessDecision`**
  Re-check immediately before a consequential action.
- **`AgentClient.require(usable: UsableMemory, risk: RiskLevel = RiskLevel.HIGH) -> AccessDecision`**
  `verify`, but raising. For a path that must not proceed.
- **`AgentClient.remember(content: str, type: str | MemoryType = MemoryType.SEMANTIC, context: Mapping[str, Any] | None = None, source_episodes: Sequence[str] = (), episode_id: str | None = None) -> str`**
  Write through the governed path, as this agent.
- **`AgentClient.episode(task_id: str, context: Mapping[str, Any] | None = None)`**
  A scoped session. Writes inside it are attributed to this agent and that episode, and an outcome recorded through it still requires a third-party verifier.
- **`AgentClient.record_outcome(episode_id: str, outcome: float, verifier_id: str)`**
  Record a verified outcome.

### `sdk.OperatorClient` (stable)

Inspection and integrity operations. Never hands content to an agent.

- **`OperatorClient.inspect(memory_id: str) -> Memory`**
  The memory whatever its state. Inspection, not an agent read.
- **`OperatorClient.explain(memory_id: str)`**
- **`OperatorClient.lineage(memory_id: str)`**
- **`OperatorClient.attention()`**
  The triage list: what needs a human, worst first.
- **`OperatorClient.retract(memory_id: str, reason: str, recipients: Sequence[str] = (), basis: str | None = None) -> Retraction`**
  Quarantine locally and durably owe the retraction to each recipient.
- **`OperatorClient.validate(memory_id: str, reason: str = 'validated') -> Memory`**
- **`OperatorClient.share(memory_id: str, scope: str = 'team', granted_capabilities: Sequence[str] = ()) -> Any`**
  Widen who may read a memory, through the firewall.
- **`OperatorClient.release(memory_id: str, reason: str = 'reviewed and released') -> Memory`**
  Undo a withdrawal. Returns the memory to `candidate`, not `active`: a reviewed retraction still leaves something nobody has re-tested.
- **`OperatorClient.erase_content(memory_id: str, reason: str) -> bool`**
  Crypto-erasure. Irreversible, and the audit trail survives it.

# Decision — proceed past P4

- **Date:** 2026-09-28
- **Evidence:** [../results/h1-causal-credit.md](../results/h1-causal-credit.md)
- **Decision: PROCEED.** The P4 kill criterion was not met; P5 is unblocked.

## What was decided

H1 was **supported** under the pre-registered rule: at ε=0.05 the amortized estimator reached ρ = 0.604 with 1.8% exploration overhead and a +0.366 margin over the naive baseline. The result is more robust at ε=0.20 (ρ = 0.761, interval entirely clear of the threshold); the triggering cell's interval straddles 0.60 and should not be quoted alone.

## What changes as a result

1. **`amortized` becomes the recommended contrastive estimator**, with `dr` as its base. It dominates below ~4000 episodes, which is where real deployments sit.
2. **DR stays, on probation.** It did not beat IPS on ranking (0.743 vs 0.739). It does produce narrower intervals, which is what retention decisions need, so it is re-examined at P5 rather than removed.
3. **H2's world config must change.** The registered P4 world gave every symptom a correct claim, so wrong claims were almost always ranked below one and never followed — median true value −0.013. H2 is about drift and injected harm and cannot use a world where harm is inert.

## What this does not establish

RuleWorld's effects are ~10x larger than the 0.02–0.05 that CRITICAL_REVIEW §2.1 expects in production. This shows the estimator recovers true value **correctly**; it does not show it does so **affordably** at realistic effect sizes. The power sweep is the part that transfers, and it says a real deployment needs far more episodes than 2000 for the same ρ.

The LLM-agent confirmation run has not happened and needs an API budget.

Memory Control Center

What your agents remember, where it came from, what it was used for, and what changed. This page only reads. Every change is a command it shows you, so nothing happens by a stray click.

      Topics

      Agents

      Every agent that has used this store, whichever tool or model it runs on: what it wrote, what it was shown, what it was refused, and what it tried to do. Connect another with memory-fabric connect <tool> --agent <id>.

      Replay what happened

      The store's history as a story, one step at a time: what agents recorded, what was shared, what was withdrawn, and which actions were allowed or blocked because of it. Open any line to follow that fact. Works for any store, including a recorded multi-agent run or memory-fabric sandbox.

        Agent actions and their evidence

        Every request to run a protected tool, with what the gate decided and the memories it rested on. Open one to see each piece of evidence as it was then and as it is now: an action whose evidence has since been withdrawn or revised is marked.

        Needs attention

        Waiting for review

        New memories are private candidates: nothing reaches retrieval until someone validates it, and nothing reaches teammates until someone shares it. Each item shows the commands for its four decisions. This page only reads; decisions are made from the command line, where each one records its reviewer.

        Memories

        Branches

        A branch holds proposed memory changes that nothing outside it can retrieve until they are merged into main. A merge preview classifies every change and says what would be applied, kept as a conflict, or refused, and why. This page only reads; merges are applied from the command line with the preview's digest.

        What agents were given

        Each context receipt records the exact memory versions and summaries an agent received, what was left out and why, and the budget it was built under. Receipts hold ids and digests only: never the query, never memory text. "Admissible now" is today's governance, not the receipt's.

        What this release does

        Generated from the capability registry, which is checked against the code and tests. Available: implemented, tested and supported. Experimental: implemented, with known limits. Planned: not implemented. Unsupported: not offered.

        Episodes

        Lifecycle and deletion

        What to keep, what to remove, and what has landed in other stores. Read-only: nothing here runs a sweep or erases anything; each finding shows its command.

        Security posture

        Read from this store, not asserted. A control being on says what the store does, not that the deployment around it is sound. Export the audit trail with memory-fabric audit-export --out FILE.
